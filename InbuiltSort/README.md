# Inbuilt Sorting using Arrays.sort()

## 🔹 Algorithm
1. Import Arrays class
2. Declare an array
3. Use Arrays.sort() method
4. Print sorted array

## 🔹 Logic
Java internally uses Dual-Pivot QuickSort for primitive data types.

## 🔹 Time Complexity
- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n log n)

## 🔹 Example

Input:  [5, 2, 8, 1, 3]  
Output: [1, 2, 3, 5, 8]
